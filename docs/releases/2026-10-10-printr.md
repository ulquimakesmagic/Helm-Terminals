# Printr launchpad (Solana) (10 October 2026)

Printr is now a Helm launchpad on Solana. GasPump is removed from the planned list (deprecated; no documented token
creation).

- **Launch:** Helm calls Printr's `POST /v0/print` with the dev wallet as creator, name, symbol, description, image
  (PNG or JPEG, max 500 KB, required), a creator buy (`spend_native`, in lamports) and the graduation size ($69k
  default, or $250k). Printr returns Solana instructions and an optional lookup table; Helm compiles them into one
  transaction paid by the dev wallet and signs it under the usual create spend guard (dev buy plus 0.1 SOL).
- **Refused before signing:** an instruction asking for any signer other than the dev wallet, a Printr quote above the
  dev buy plus 0.1 SOL, accounts on another chain, malformed instructions, a missing lookup table.
- **Fees:** Helm's $10 launch fee and 1% Solana trading fee apply as on other Solana launchpads. Printr documents no
  partner split, so there is no Helm creator-reward share; Printr's creator fees go to the dev wallet.
- **Trading:** through Jupiter's swap API (`JUPITER_API_KEY`). If Jupiter can't route a fresh Printr token yet, the
  trade preview says so; buy on app.printr.money meanwhile.
- **Claims:** on app.printr.money (Printr's claim API is a separate protobuf service, not integrated).

Config: `PRINTR_API_URL` (default `https://api-preview.printr.money`), optional `PRINTR_API_KEY`.

Not verified live: the request and response shapes come from Printr's published OpenAPI types (printr-mcp,
`packages/sdk/src/api.gen.d.ts`, July 2026) and are tested against a mock. Whether a 0 SOL creator buy is accepted,
and whether Jupiter routes Printr curves, are unconfirmed. **Rehearse one small launch** (for example 0.05 SOL dev
buy) before announcing it.
