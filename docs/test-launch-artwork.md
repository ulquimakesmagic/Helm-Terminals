# Test Launch artwork

The landing and sign-in previews use `frontend/src/assets/test-launch-token.webp`.
It is an original generated illustration for the explicitly labeled **Test Launch
/$TEST** demonstration, not a real token, market price or launch receipt.

Generated with the built-in image-generation tool on 16 November 2026. The
selected transparent PNG was resized to 640 × 640 and compressed to WebP, keeping
its alpha channel. Helm's existing SVG logo supplies the animated steering wheel;
CSS supplies the signal and token motion. Reduced-motion preferences and a pause
control are supported.

## Final generation prompt

Use case: stylized-concept. Asset: original premium token artwork for Helm
Terminals' clearly labeled Test Launch / $TEST product demonstration. Create a
single isolated three-quarter-view precision-machined titanium token, a sculpted
nautical ship's helm with eight spokes forming its central relief, subtle luminous
emerald/teal glass core, gunmetal beveled rim, fine concentric etched circuitry,
controlled realistic studio reflections, extremely polished physical collectible
with restrained futuristic crypto character. A small orbit of two translucent
emerald fragments gives dimensionality but remains close to the coin. Transparent
background, no environmental backdrop, no pedestal, no text, no lettering, no
ticker, no currency logos, no Bitcoin symbol, no watermark. Centered balanced
square composition, full object in frame with generous clear margins, clearly
readable at small avatar scale. Dark luxury material, sharp crisp silhouette,
no gaudy gold, no neon rainbow.
